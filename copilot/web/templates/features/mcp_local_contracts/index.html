Local MCP contracts

These stdio tools read artifacts from Proofie's configured local database. The allowlist stores only actor-to-case authorization IDs; it is not a second case-data store. No provider client, model, send, approve, or accept-claim capability is registered.

Run over stdio

{{ command }}

Configure PROOFIE_MCP_LOCAL_REGISTRY to an owned local JSON file shaped as {"actor_cases":{"local-user":["PP-R-DEMO-0000001"]}}. Case facts are read from config.db_path() through Proofie's repository. Configure the server actor through PROOFIE_MCP_LOCAL_ACTOR. Neither actor nor permissions are accepted from tool arguments. Audit JSONL and prepared notes stay under the MCP subfolder of the local data folder.

Prepared notes are local review material. They are not PayPal state and are not sent. Use a real MCP client to discover and invoke tools; the Python service is not itself the protocol.
